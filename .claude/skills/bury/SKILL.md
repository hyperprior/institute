---

# Bury

1. Run `just hp bury <name>`.
2. Write the epitaph in the generated log entry: what it was, what was learned
   (including "it didn't work, because…"), and anything worth reusing. A good
   burial is a result. Keep the tone light.
3. Leave the code in place. Buried projects stay readable in the graveyard. To
   revive one later, start a new sketch with `--from <name>`.
